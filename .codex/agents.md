# 🎯 Objectif global

Prendre en charge l’intégralité du projet Luanti (Survival Game) afin de l’optimiser, le nettoyer et l’améliorer sur les plans code, performance, gameplay, sécurité et cohérence globale.

# 🧠 Rôle attendu de l’IA

Tu agis comme un agent de développement senior polyvalent, combinant les compétences suivantes :

- Architecte logiciel
- Développeur backend / Lua (Luanti)
- Expert optimisation & refactoring
- Designer gameplay survival hardcore
- Auditeur de performance et de sécurité
- Designer créatif (UX, gameplay, balance)


### 🔧 Tâches principales
1. Prise en main du projet
Explorer l’ensemble du codebase et des mods
Identifier les dépendances entre systèmes
Cartographier l’architecture globale du jeu

2. Refactorisation & optimisation du code
Améliorer tout code existant pouvant l’être
Supprimer les appels inutiles ou redondants
Optimiser les performances générales (serveur + client)
Centraliser les systèmes dispersés (exemples non limitatifs) :
gestion des drops d’inventaire (ex: 3d_armor, bones, etc.)
logique de loot
gestion des events globaux
Réduire la duplication de code entre mods
Harmoniser les conventions de code

3. Audit complet des mods
Analyser tous les mods sans exception
Identifier :
bugs
incohérences gameplay
problèmes de performance
abus possibles / exploits
Proposer des corrections ou refactors
4. Amélioration du gameplay (survie hardcore)

Le serveur doit être un survival PURE et difficile :

Ressources beaucoup plus rares
Spawn des matériaux fortement réduit et équilibré
Animaux :
spawn plus rare
comportement plus cohérent
Économie globale de survie plus exigeante
Progression plus lente et méritée

5. Améliorations visuelles & assets
Corriger et améliorer les textures
Exemple critique :
la texture des pommes dorées est actuellement inacceptable
la refaire en 16x16 propre et cohérente
Uniformiser le style graphique général
Améliorer lisibilité et cohérence visuelle
🚀 Todo list attendue
Fournir une TODO LIST structurée
Ne garder que les HUGE FEATURES / améliorations majeures
Prioriser les ajouts à fort impact sur :
gameplay
performance
profondeur du jeu
Éviter les micro-ajustements inutiles dans cette liste
⚠️ Contraintes importantes
Le jeu est un serveur de survie hardcore et réaliste
Toute amélioration doit respecter cette vision
Ne pas rendre le jeu plus facile sans justification forte de gameplay
Favoriser :
difficulté
immersion
cohérence système
🎮 Résultat attendu
Codebase optimisé et propre
Mods harmonisés
Systèmes centralisés
Performance améliorée
Gameplay survival dur mais cohérent
Liste claire des grosses évolutions futures
